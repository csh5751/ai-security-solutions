PoC 편집 기능, 배선 가이드

지금 배포된 progress.html의 편집 모드가 실제로 저장까지 되려면, Cloudflare 대시보드에서 딱 세 가지 — KV 저장소, 바인딩, 비밀번호 두 개 — 를 연결해줘야 합니다. 코드는 이미 준비돼 있고, 여기 있는 건 전부 클릭 몇 번으로 끝나는 설정입니다. 위에서부터 순서대로 하시면 됩니다.

1 KV 저장소 만들기

dash.cloudflare.com 로그인 → 왼쪽 메뉴 Storage & Databases → KV

Cloudflare 대시보드에 로그인하고, 왼쪽 사이드바에서 Storage & Databases → KV로 들어갑니다.

Create instance 버튼을 누릅니다. (구버전 화면에는 "Create namespace"로 표시되기도 합니다 — 같은 버튼입니다.)

이름은 자유롭게 지어도 됩니다 (예: poc-progress). Add를 눌러 생성을 완료합니다.

2 Pages 프로젝트에 연결(바인딩)

Workers & Pages → ai-security-solutions → Settings → Bindings

왼쪽 사이드바 Workers & Pages → ai-security-solutions 프로젝트 클릭 → 상단 Settings 탭.

Bindings 메뉴로 들어가 Add 클릭 → 타입에서 KV namespace를 선택합니다. (구버전 화면에는 Functions → KV namespace bindings 였는데, 지금은 Bindings 하나로 통합됐습니다.)

아래 값을 철자·대소문자 그대로 입력하세요. 코드가 이 이름으로 직접 참조합니다.

Variable namePOC_KV
KV namespace1단계에서 만든 네임스페이스 선택

Save. 화면에 Production / Preview 환경 구분이 보이면, 두 환경 모두에 같은 바인딩을 추가해주세요.

3 비밀번호·서명키 등록

같은 Settings 화면 → Variables and Secrets

Variables and Secrets 메뉴로 들어가 Add를 두 번 눌러 아래 두 개를 등록합니다. Type 드롭다운(또는 체크박스)이 보이면 반드시 Secret(=Encrypt)로 선택하세요 — 일반 Text로 저장하면 코드 동작은 같지만 값이 대시보드에 그대로 노출됩니다.

이름EDIT_PASSWORD값편집 모드에 쓸 비밀번호
이름SESSION_SECRET값아무도 모를 무작위 긴 문자열
TIP SESSION_SECRET 값이 마땅히 없다면: 새 브라우저 탭을 열고 F12(개발자 도구) → Console 탭에서 crypto.randomUUID()+crypto.randomUUID()를 입력해 나온 문자열을 그대로 복사해 붙여넣으면 됩니다.

Save 후, 화면 상단에서 환경을 Preview로 전환해 위 두 값을 동일하게 한 번 더 등록합니다.

4 업체 자동 추가(AI 조사) 기능 연결

같은 Settings 화면 → Variables and Secrets  +  console.anthropic.com

진행현황 화면에서 업체명만 입력하면 AI가 웹 검색으로 정확한 이름과 정보를 조사해 자동 등록해주는 기능을 쓰려면, Anthropic API 키가 필요합니다. console.anthropic.com에서 로그인 후 API 키를 하나 발급받으세요.

3단계와 같은 Variables and Secrets 화면에서 Add를 눌러 아래 값을 Secret(=Encrypt) 타입으로 등록합니다. Production/Preview 두 환경 모두에 등록해주세요.

이름ANTHROPIC_API_KEY값방금 발급받은 API 키

Anthropic Console의 Settings → Web Search(또는 조직 설정 내 Web Search 항목)에서 웹 검색 도구를 활성화합니다. 조직 관리자 권한이 필요할 수 있습니다.

비용 안내 웹 검색은 1,000회당 약 $10 수준의 비용이 발생합니다. 업체 하나를 추가할 때 몇 번의 검색만 사용하므로 비용은 미미하지만, 조직 계정에 청구되는 실비용이니 참고해주세요.
5 재배포 후 실제로 눌러보기

여기까지 끝나면 Claude에게 "설정 끝났어"라고 알려주세요. 방금 등록한 바인딩·환경변수는 다음 배포부터 적용되기 때문에, 제가 코드를 push해서 새 배포를 트리거해야 실제로 반영됩니다.

배포가 끝나면 실제 사이트의 progress.html로 들어가 우측 상단 편집 모드 켜기를 클릭합니다.

3단계에서 정한 EDIT_PASSWORD 값을 입력 → 벤더 아무 행이나 값을 바꾸고 저장 클릭.

"저장됨 ✓"이 뜨고, 새로고침해도 값이 그대로 남아있으면 전체 설정이 정상적으로 끝난 것입니다.

막히는 부분이 있으면

화면에 보이는 메뉴 이름이 여기와 살짝 다르거나(Cloudflare가 종종 UI를 바꿉니다), 저장이 안 되거나, 편집 모드에서 비밀번호가 계속 틀렸다고 나오면 — 어느 단계에서 무슨 화면이 보이는지 그대로 알려주세요. 화면 문구 그대로 캡처해서 붙여넣어 주셔도 됩니다.
